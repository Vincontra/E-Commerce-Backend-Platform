# Scalable E-Commerce Backend Platform

🚧 **Project Status:** Currently under development.

A scalable backend for an E-Commerce application built using **Java, Spring Boot, Spring Security, JWT, Hibernate/JPA, and MySQL**. The project follows a layered architecture and aims to provide secure, scalable, and maintainable REST APIs for core e-commerce functionalities.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- Hibernate / JPA
- MySQL
